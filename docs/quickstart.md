# DTRules Quick Start

This file used to document a Java/Maven setup that was archived in
commit 7f742ab16 (Go-primary restructure). The authoritative quick
start for the current Go-primary binary lives inside `dtrules` itself:

```bash
dtrules docs cli
```

That topic covers install, project init, the Excel-authored and
XML-authored flows, validate / verify, and CI integration. See also:

- `dtrules docs workflow` — `dtrules build` pipeline deep-dive
- `dtrules docs el` — Expression Language reference
- `dtrules docs decision-tables` — decision table structure
- `dtrules docs edd` — Entity Data Dictionary

The legacy Java implementation is preserved under `legacy/java/` but is
no longer maintained.
