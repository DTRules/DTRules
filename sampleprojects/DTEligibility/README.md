# DTEligibility Sample Project

**Status:** Work in Progress

This sample project contains eligibility determination rules. Currently only the compiled XML files are present.

## Contents

- `xml/eligibility_edd.xml` - Entity Definition Document
- `xml/eligibility_dt.xml` - Decision Tables
- `xml/eligibility_map.xml` - Data Mapping
