# Multi-File XML Quick Reference

## Daily Commands

### Validate Your Changes
```bash
cd sampleprojects/TaxReturn
python3 scripts/validate_extraction.py > /tmp/validate.log 2>&1
tail -50 /tmp/validate.log
```

### Merge for Testing
```bash
cd sampleprojects/TaxReturn
python3 scripts/merge_files.py > /tmp/merge.log 2>&1
tail -30 /tmp/merge.log
```

### Run Tests
```bash
cd go
go test ./pkg/dtrules/... -run TestTaxReturn > /tmp/test.log 2>&1
tail -50 /tmp/test.log
```

## File Structure

```
xml/
├── TaxReturn_dt.xml              # Merged (generated, don't commit)
├── TaxReturn_edd.xml             # Merged (generated, don't commit)
├── TaxReturn_dt_core.xml         # Federal core tables
├── TaxReturn_edd_core.xml        # Federal core entities
└── states/
    ├── XX_dt.xml                 # State decision tables (commit this)
    └── XX_edd.xml                # State entities (commit this)
```

## New State Checklist

1. Copy templates
   ```bash
   cp xml/states/TEMPLATE_dt.xml xml/states/XX_dt.xml
   cp xml/states/TEMPLATE_edd.xml xml/states/XX_edd.xml
   ```

2. Edit files (use correct TABLE_NUMBER from above)

3. Validate
   ```bash
   python3 scripts/validate_extraction.py > /tmp/validate.log 2>&1
   ```

4. Merge
   ```bash
   python3 scripts/merge_files.py > /tmp/merge.log 2>&1
   ```

5. Test
   ```bash
   cd ../../go && go test ./pkg/dtrules/... -run TestTaxReturn > /tmp/test.log 2>&1
   ```

6. Commit (only state files!)
   ```bash
   git add xml/states/XX_dt.xml xml/states/XX_edd.xml
   git commit -m "feat: implement XX state tax (#NNN)"
   ```

## Common Errors

### Duplicate Table Number
```
ERROR: Table 40400 appears in multiple files
```
→ Each state needs unique TABLE_NUMBER from numbering scheme above

### FILE_PATH Mismatch
```
WARNING: FILE_PATH 'states/CA/...' but file is NY_dt.xml
```
→ Update FILE_PATH to match state code

### XML Parse Error
```
ERROR: XML parse error: mismatched tag: line 45
```
→ Fix XML syntax (unclosed tag, missing quote, etc.)

### Missing Tables
```
ERROR: Missing 5 tables in extracted files
```
→ Extract missing tables from TaxReturn_dt.xml into proper files

## Files to Commit vs. Not Commit

### ✅ DO COMMIT
- `xml/states/XX_dt.xml` (your state)
- `xml/states/XX_edd.xml` (your state)
- `testfiles/TestScenarios/State/XX/*` (test cases)

### ❌ DON'T COMMIT
- `xml/TaxReturn_dt.xml` (generated by merge)
- `xml/TaxReturn_edd.xml` (generated by merge)
- `/tmp/*.log` (temporary logs)
