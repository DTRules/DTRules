```

│
├── taxpayers[]           (Array of taxpayer)
│   ├── incomes[]
│   └── notes[]
│
├── dependents[]          (Array of dependent)
├── properties[]          (Array of property)
├── vehicles[]            (Array of vehicle)
├── deductions[]          (Array of deduction)
├── credits[]             (Array of credit)
├── results[]             (Array of result)
└── state_tax_results[]   (Array of state_tax_result)

Core Entities (in TaxReturn_edd_core.xml):
- job
- taxpayer
- dependent
- result
- constants
- ...

State Entities (in XX_edd.xml):
- State-specific constants
- State-specific result fields
```

## Error Detection Matrix

| Error Type              | Validation | Merge | Fix Priority |
|------------------------|-----------|-------|--------------|
| Malformed XML          | ✓         | ✓     | P1 (blocks)  |
| Duplicate TABLE_NUMBER | ✓         | ✓     | P1 (blocks)  |
| Missing tables         | ✓         | -     | P2           |
| Missing entities       | ✓         | -     | P2           |
| FILE_PATH mismatch     | ✓         | -     | P3 (warn)    |
| Field count diff       | ✓         | -     | P3 (warn)    |

## State Implementation Pattern

```
1. Research
   ├── Tax rate
   ├── Standard deduction
   ├── Exemptions
   └── 2-3 key rules

2. Create Files
   ├── cp TEMPLATE_dt.xml XX_dt.xml
   └── cp TEMPLATE_edd.xml XX_edd.xml

3. Implement
   ├── Add constants to XX_edd.xml
   └── Add decision table to XX_dt.xml
       ├── Assign TABLE_NUMBER (from numbering scheme)
       └── Set FILE_PATH (states/XX/...)

4. Validate
   └── python3 scripts/validate_extraction.py

5. Merge & Test
   ├── python3 scripts/merge_files.py
   └── go test ./pkg/dtrules/...

6. Commit
   ├── git add xml/states/XX_dt.xml
   ├── git add xml/states/XX_edd.xml
   └── git commit -m "feat: implement XX state tax"
```

## Future Architecture

### Phase 1: Current (Multi-file Development)
```
Multi-file source ──merge──> Monolithic ──load──> DTRules Engine
```

### Phase 2: Future (Direct Multi-file Loading)
```
Multi-file source ──────────load directly──────> DTRules Engine
                                                        │
                                                        ├── Load only needed states
                                                        ├── Faster initialization
                                                        └── Less memory
```

### Phase 3: Advanced (Incremental Compilation)
```
Multi-file source ──watch changes──> Incremental Compiler
                                             │
                                             ├── Only reprocess changed files
                                             ├── Cache parsed results
                                             └── Hot reload in dev mode
```

## Benefits Summary

| Aspect              | Monolithic | Multi-File |
|---------------------|-----------|------------|
| Merge conflicts     | High      | None       |
| Navigation          | Difficult | Easy       |
| Parallel dev        | No        | Yes        |
| Review clarity      | Poor      | Excellent  |
| Testing isolation   | Hard      | Easy       |
| Load time           | Fast¹     | Future²    |

¹ Current DTRules engine loads single file quickly
² Future enhancement: load only needed states
