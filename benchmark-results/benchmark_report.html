Performance Summary

Key Findings:

  • native-asm (Plan 9 Assembly) is the fastest runtime, achieving 9-95 ns/op
  • go runtime is 2-4x slower than native-asm at 24-362 ns/op
  • java (estimated) performs between native-asm and go at 8-266 ns/op
  • x86-64-asm (CGO) has significant overhead from CGO calls at 157-283 ns/op

Recommendations:

  • Use native-asm for maximum performance on amd64
  • Use go runtime for portability and debugging
  • The x86-64-asm CGO approach is not recommended due to call overhead
